# Tailwind CSS 完整講義

> Tailwind CSS 是一套 **Utility-First（工具優先）** 的 CSS 框架。
> 它不給你「元件」，而是給你一堆小的、單一用途的 class（例如 `flex`、`pt-4`、`text-center`），讓你直接在 HTML 裡「組合」出樣式，幾乎不用自己寫 CSS。

## 1. 什麼是 Utility-First？

> **對應範例**：[examples/01-basics.html](examples/01-basics.html) — 打開後對照本章寫法，看工具類組合出來的實際畫面。

傳統寫法：先想一個 class 名稱，再到 CSS 檔寫規則。

```html
<div class="card">...</div>
```
```css
.card {
  padding: 16px;
  border-radius: 8px;
  background: white;
  box-shadow: 0 2px 8px rgba(0,0,0,.1);
}
```

Tailwind 寫法：直接在 HTML 用工具類組合，**不寫 CSS**。

```html
<div class="p-4 rounded-lg bg-white shadow-md">...</div>
```

- `p-4` = `padding: 1rem`
- `rounded-lg` = `border-radius: 0.5rem`
- `bg-white` = `background: white`
- `shadow-md` = 一組預設陰影

### 為什麼這樣比較好？

- **不用想 class 名字**：不再糾結 `.card-wrapper-inner` 該叫什麼。
- **不用切換檔案**：改樣式就在 HTML 當下改，所見即所得。
- **不會樣式衝突**：沒有全域 CSS 互相覆蓋的問題。
- **檔案不膨脹**：Tailwind 只把「你用到的」class 打包進最終 CSS，沒用到的自動移除。
- **設計一致性**：間距、顏色、字級都來自預設的設計系統（`4` `8` `16`… 而非隨手 `13px`）。

### 常見疑慮：「HTML 會不會很醜很長？」

會比較長，但實務上：搭配元件框架（React/Vue）把重複的東西封裝成元件，或用 `@apply` 抽出常用組合即可。多數團隊實測後認為**維護性利大於弊**。

## 2. 與傳統 CSS / Bootstrap 的差異

| | 傳統 CSS / Sass | Bootstrap | Tailwind CSS |
|---|---|---|---|
| 核心單位 | 自訂 class | 現成元件（`.btn`、`.card`）| 工具類（`.flex`、`.p-4`）|
| 客製彈性 | 高（但要自己寫）| 低（改元件較麻煩）| 高（組合工具類）|
| 長相是否雷同 | 不會 | 容易「一看就是 Bootstrap」| 不會 |
| 學習重點 | CSS 屬性 | 記元件與 grid 系統 | 記工具類命名規則 |
| 最終檔案大小 | 看你怎麼寫 | 較大（整包）| 很小（只留用到的）|

> 一句話：**Bootstrap 給你組好的家具，Tailwind 給你標準化的積木。**

## 3. 安裝與環境（CDN / CLI / Vite）

> 本教材**一律以 Tailwind CSS v4 教學與練習**（官方最新版），所有範例與練習題都是 v4 寫法。
>
> 標示「**v3 補充**」的段落只是給需要維護舊專案的人參考，**第一次學可以直接略過**。

### 方法 A：Play CDN（練習／Demo 最快，不需安裝）

在 HTML `<head>` 加一行，即可使用所有工具類。**僅適合學習與雛形，不建議上線**（檔案較大、無法完整客製）。

```html
<!-- Tailwind v4 瀏覽器版 -->
<script src="https://unpkg.com/@tailwindcss/browser@4"></script>
```

> **v3 補充**：v3 的 Play CDN 是 `<script src="https://cdn.tailwindcss.com"></script>`，本教材不使用。

本教材 `examples/` 內的 HTML 都用這種方式，直接用瀏覽器打開就能看效果。

### 方法 B：Tailwind CLI

```bash
npm install tailwindcss @tailwindcss/cli

# 建立輸入檔 input.css，內容只要：
#   @import "tailwindcss";

# 編譯 + 監看
npx @tailwindcss/cli -i input.css -o output.css --watch
```

### 方法 C：Vite（正式專案推薦）

```bash
npm create vite@latest my-app
cd my-app
npm install tailwindcss @tailwindcss/vite
```

`vite.config.js`：

```js
import tailwindcss from '@tailwindcss/vite';

export default {
  plugins: [tailwindcss()],
};
```

`src/style.css`：

```css
@import "tailwindcss";
```

> **v3 補充**：v3 需要 `tailwind.config.js` 設定 `content` 掃描路徑，並在 CSS 寫 `@tailwind base; @tailwind components; @tailwind utilities;`。v4 簡化成一行 `@import "tailwindcss";`，會自動偵測要掃描的檔案——**照 v4 寫就好**。

## 4. 核心工具類速查

> **對應範例**：[examples/01-basics.html](examples/01-basics.html) — 間距／文字／顏色深淺三個區塊各附「動手改」提示。

工具類命名有固定規則，記住規則就能舉一反三。

### 間距（Spacing）— 最常用

數字是「間距刻度」，**1 = 0.25rem = 4px**，所以 `p-4` = 16px。

| Class | 意義 |
|-------|------|
| `p-4` / `px-4` / `py-4` / `pt-4` | padding（全 / 左右 / 上下 / 上）|
| `m-4` / `mx-auto` / `mt-2` | margin（`mx-auto` 水平置中）|
| `gap-4` | flex/grid 的間距 |
| `space-x-4` | 子元素之間的水平間距 |

### 尺寸（Sizing）

| Class | 意義 |
|-------|------|
| `w-full` / `w-1/2` / `w-64` | 寬 100% / 50% / 16rem |
| `h-screen` | 高度 = 視窗高 |
| `max-w-md` | 最大寬度（sm/md/lg/xl…）|
| `min-h-screen` | 最小高度滿版 |

### 文字（Typography）

| Class | 意義 |
|-------|------|
| `text-sm` / `text-lg` / `text-2xl` | 字級 |
| `font-bold` / `font-medium` | 字重 |
| `text-center` / `text-right` | 對齊 |
| `text-gray-600` | 文字顏色（顏色-深淺）|
| `leading-relaxed` | 行高 |
| `tracking-wide` | 字距 |

### 顏色（Color）

命名規則：`屬性-顏色-深淺`，深淺從 `50`（最淺）到 `950`（最深）。

```html
<div class="bg-blue-500 text-white border-blue-700">...</div>
```

- 背景：`bg-red-500`
- 文字：`text-green-600`
- 邊框：`border-gray-300`
- 常見色系：`slate` `gray` `red` `orange` `amber` `yellow` `green` `teal` `blue` `indigo` `purple` `pink`

### 邊框與圓角、陰影

| Class | 意義 |
|-------|------|
| `border` / `border-2` | 邊框粗細 |
| `rounded` / `rounded-lg` / `rounded-full` | 圓角 |
| `shadow` / `shadow-md` / `shadow-xl` | 陰影 |

### 顯示與定位

| Class | 意義 |
|-------|------|
| `block` / `inline-block` / `hidden` | display |
| `relative` / `absolute` / `fixed` | position |
| `top-0` / `right-4` / `inset-0` | 定位偏移 |
| `z-10` | z-index |
| `overflow-hidden` / `overflow-auto` | 溢出處理 |

### 任意值（Arbitrary values）

預設刻度不夠用時，可用方括號寫任意值：

```html
<div class="top-[117px] bg-[#1da1f2] w-[73%] text-[13px]">...</div>
```

## 5. Flexbox 與 Grid 佈局

> **對應範例**：[examples/02-flex-grid.html](examples/02-flex-grid.html) — 導覽列（Flex）、三欄卡片（Grid）、水平垂直置中。

### Flexbox

```html
<div class="flex items-center justify-between gap-4">
  <div>左</div>
  <div>右</div>
</div>
```

| Class | 意義 |
|-------|------|
| `flex` | display: flex |
| `flex-col` | 改為直向排列 |
| `items-center` | 交叉軸置中（align-items）|
| `justify-between` | 主軸兩端對齊（justify-content）|
| `justify-center` | 主軸置中 |
| `flex-wrap` | 允許換行 |
| `flex-1` | 佔滿剩餘空間 |

### 用 Flex 做多欄：`flex-1` vs `w-1/2`

同樣是「兩欄各半」，有兩種寫法，差別在**誰決定寬度**：

```html
<!-- A. flex-1：平均分配「剩下的空間」-->
<div class="flex gap-4">
  <div class="flex-1">左</div>
  <div class="flex-1">右</div>
</div>

<!-- B. w-1/2：各自寫死父層寬度的 50% -->
<div class="flex gap-4">
  <div class="w-1/2">左</div>
  <div class="w-1/2">右</div>
</div>
```

|  | `flex-1` | `w-1/2`、`w-1/3` |
| --- | --- | --- |
| 寬度怎麼算 | 剩餘空間平均分（gap 已先扣掉） | 父層寬度的固定比例 |
| 加了 `gap` | 沒問題，自動變窄 | 比例失真（50% + 50% + gap > 100%，見下方說明） |
| 內容很長時 | 會一起被壓縮，欄寬仍相等 | 撐不下去就不再收縮，內容溢出 |
| 適合 | 等分欄位、自適應版面（最常用） | 需要精確比例、或搭配 `flex-wrap` 換行 |

> **`w-1/2` + `gap-4` 到底會怎樣？** 加起來確實超過 100%，但實際結果取決於 `flex-wrap`：
>
> - **預設 `flex`（不換行）**：flex 項目預設 `flex-shrink: 1`，兩欄會被等量壓縮成 `calc(50% - 8px)`。**不會爆版**，但也不再是真正的 50%——想要精確比例時就失真了。
> - **加 `flex-wrap`**：一列放不下，第二欄整個換到下一行，變成上下各一欄。
> - **加 `shrink-0`（或內容有 `min-width` 撐著，例如長單字、`whitespace-nowrap`）**：不能收縮又不能換行，這時才會真的溢出父層。
>
> 所以「爆版」只發生在第三種情況。真的要用比例又要間距，改用 `w-[calc(50%-0.5rem)]`，或直接用 `flex-1`／`grid`。

不等比例（左 2 右 1）：`flex-[2]` + `flex-1`，或 `w-2/3` + `w-1/3`。

經典三欄 1 : 2 : 1（左右側欄 + 中間主內容）：`flex-1` + `flex-[2]` + `flex-1`，或 `w-1/4` + `w-1/2` + `w-1/4`（後者不要加 `gap`，改用內距）。

手機一欄、桌機多欄：`flex flex-col md:flex-row`。

### Grid

```html
<div class="grid grid-cols-3 gap-4">
  <div>1</div><div>2</div><div>3</div>
</div>
```

| Class | 意義 |
|-------|------|
| `grid` | display: grid |
| `grid-cols-3` | 3 欄 |
| `col-span-2` | 跨 2 欄 |
| `gap-4` | 格線間距 |

**經典置中（水平垂直都置中）**：

```html
<div class="flex items-center justify-center h-screen">
  <div>置中內容</div>
</div>
```

## 6. 響應式設計 RWD（斷點）

> **對應範例**：[examples/03-responsive-state.html](examples/03-responsive-state.html) — 拉寬／縮窄視窗觀察 1 → 2 → 4 欄的切換點。

Tailwind 是 **Mobile First**：**沒加前綴的樣式是手機版**，加斷點前綴才是「該尺寸(含)以上」套用。

| 前綴 | 生效寬度 | 對應裝置 |
|------|---------|---------|
| （無）| 全部 | 手機 |
| `sm:` | ≥ 640px | 大手機 / 直立平板 |
| `md:` | ≥ 768px | 平板 |
| `lg:` | ≥ 1024px | 筆電 |
| `xl:` | ≥ 1280px | 桌機 |
| `2xl:` | ≥ 1536px | 大桌機 |

範例：手機一欄、平板兩欄、桌機四欄。

```html
<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-4">
  ...
</div>
```

> 常見錯誤：想在「手機」套樣式卻寫 `sm:`。記住——**手機版不用前綴**，`sm:` 是 640px 以上。

## 7. 狀態變體：hover / focus / group / peer

> **對應範例**：[examples/03-responsive-state.html](examples/03-responsive-state.html)、[examples/05-component-card.html](examples/05-component-card.html)

用「變體前綴 `:`」在特定狀態套樣式。

```html
<button class="bg-blue-500 hover:bg-blue-700 focus:ring-2 active:scale-95">
  按鈕
</button>
```

常用變體：`hover:` `focus:` `active:` `disabled:` `focus-within:` `first:` `last:` `odd:` `even:`

### `group`：依「父層狀態」改變子元素

在父層加 `group`，子元素用 `group-hover:` 反應父層的 hover。

```html
<a href="#" class="group block p-4 border">
  <h3 class="group-hover:text-blue-600">標題</h3>
  <p class="text-gray-500 group-hover:text-gray-700">滑到整張卡都會變色</p>
</a>
```

### `peer`：依「兄弟元素狀態」改變

常用於表單：input 有 `peer`，後面的元素用 `peer-focus:`、`peer-invalid:` 反應。

```html
<input type="email" class="peer border" />
<p class="hidden peer-invalid:block text-red-500">Email 格式錯誤</p>
```

## 8. 深色模式 Dark Mode

> **對應範例**：[examples/04-darkmode-theme.html](examples/04-darkmode-theme.html) — 右上角按鈕可手動切換深／淺色。

用 `dark:` 前綴指定深色模式下的樣式。

```html
<div class="bg-white text-gray-900 dark:bg-gray-800 dark:text-white">
  自動或手動切換深淺色
</div>
```

- **預設**：跟隨作業系統設定（`prefers-color-scheme`）。
- **手動切換**：在 `<html>` 加/移除 `class="dark"`（需設定 selector 策略），用 JS 切換：

```js
document.documentElement.classList.toggle('dark');
```

> v4 設定手動策略：在 CSS 加 `@custom-variant dark (&:where(.dark, .dark *));`。

> **v3 補充**：v3 是在 `tailwind.config.js` 設 `darkMode: 'class'`。

## 9. 自訂主題（`@theme`）

> **對應範例**：[examples/04-darkmode-theme.html](examples/04-darkmode-theme.html) — `@theme` 定義 `--color-brand` 後直接用 `bg-brand`。

### 用 CSS 的 `@theme`

v4 把設定搬進 CSS，用 `@theme` 定義設計 token，會自動生成對應工具類。**這就是本教材唯一使用的客製方式。**

```css
@import "tailwindcss";

@theme {
  --color-brand: #6366f1;        /* 產生 bg-brand / text-brand… */
  --color-brand-dark: #4f46e5;
  --font-display: 'Noto Sans TC', sans-serif;
  --spacing-18: 4.5rem;          /* 產生 p-18 / m-18… */
  --breakpoint-3xl: 1920px;      /* 新增 3xl: 斷點 */
}
```

```html
<button class="bg-brand hover:bg-brand-dark font-display p-18">品牌按鈕</button>
```

### v3 補充：`tailwind.config.js`（舊專案才需要）

```js
module.exports = {
  content: ['./src/**/*.{html,js}'],
  theme: {
    extend: {
      colors: {
        brand: { DEFAULT: '#6366f1', dark: '#4f46e5' },
      },
      spacing: { 18: '4.5rem' },
    },
  },
};
```

> **v3 補充**：config 裡的 `extend` 是「新增」，直接寫在 `theme` 底下會「覆蓋」預設值，所以通常用 `extend`。v4 的 `@theme` 預設就是「新增」，不會蓋掉內建刻度。

## 10. 重複樣式的處理：`@apply` 與元件抽取

> **對應範例**：[examples/05-component-card.html](examples/05-component-card.html) — 三張卡片 class 完全重複，正好拿來練習抽元件。

當同一組工具類到處重複（例如按鈕），有兩種做法：

### 做法 A：元件化（首選）

用 React/Vue 把它包成元件，`class` 只寫一次：

```jsx
function Button({ children }) {
  return <button className="px-4 py-2 rounded-lg bg-blue-500 text-white hover:bg-blue-600">{children}</button>;
}
```

### 做法 B：`@apply` 抽出自訂 class

在 CSS 用 `@apply` 把工具類組合成語意化 class：

```css
@import "tailwindcss";

@layer components {
  .btn {
    @apply px-4 py-2 rounded-lg font-semibold transition;
  }
  .btn-primary {
    /* 直接列出 utility，不要用 @apply 去串接另一個自訂類 .btn */
    @apply px-4 py-2 rounded-lg font-semibold transition
           bg-blue-500 text-white hover:bg-blue-600;
  }
}
```

```html
<button class="btn-primary">送出</button>
```

> 兩個提醒：
> 1. 別過度使用 `@apply`。官方建議 **優先用元件抽取**，`@apply` 只在少數真的重複、又無法元件化時使用（否則就退回傳統 CSS 的老問題了）。
> 2. **`@apply` 請直接列 utility class**，不要 `@apply btn ...` 去串接「另一個自訂類」——v4 中這種串接不保證有效，把 utility 直接寫出來最穩妥。

## 11. 推薦工具與最佳實踐

### 必裝工具

- **[Tailwind CSS IntelliSense](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss)**（VS Code 擴充，擴充 ID `bradlc.vscode-tailwindcss`）：class 自動補全、hover 顯示對應 CSS、顏色預覽、錯誤 class 提示。**強烈建議必裝**。
- **Prettier + `prettier-plugin-tailwindcss`**：自動把 class 依官方順序排序，維持整潔。
- **官方 Playground**（[play.tailwindcss.com](https://play.tailwindcss.com)）：線上即時試玩、看編譯結果。

安裝 IntelliSense：VS Code 左側 Extensions（`Cmd/Ctrl + Shift + X`）搜尋「Tailwind CSS IntelliSense」，或用命令列：

```bash
code --install-extension bradlc.vscode-tailwindcss
```

> 用 Play CDN 的練習檔（本教材的 `examples/`、`practice/`）補全可能不會啟動——擴充是靠專案裡的 Tailwind 設定檔判斷要不要啟用。
> 在專案根目錄放一個只有一行 `@import "tailwindcss";` 的 `tailwind.css`（v4 寫法）即可喚醒它，這個檔案不影響 Play CDN 的執行。
>
> 再加上這段 `.vscode/settings.json`，讓補全在 `class="…"` 字串內也會跳出來：

```json
{
  "tailwindCSS.includeLanguages": { "html": "html" },
  "tailwindCSS.emmetCompletions": true,
  "editor.quickSuggestions": { "strings": true },

  // VS Code 內建 CSS 檢查不認識 v4 的 @theme / @utility / @custom-variant，
  // 會出現 "Unknown at rule" 黃色警告，關掉即可（不影響編譯）
  "css.lint.unknownAtRules": "ignore",
  "scss.lint.unknownAtRules": "ignore"
}
```

> **常見困擾**：在 CSS 或 `<style type="text/tailwindcss">` 裡寫 `@theme`、`@apply`、`@utility` 時，編輯器出現黃色波浪線「Unknown at rule @theme」。
> 那是 VS Code 內建的 CSS 檢查器不認得 Tailwind 的自訂語法，**程式碼本身沒有錯、也能正常編譯**。加上上面那兩行 `unknownAtRules` 設定就不會再跳警告。

### 最佳實踐

1. **善用設計刻度**：優先用 `p-4`、`text-lg` 這種刻度，少用 `p-[13px]` 任意值，維持一致性。
2. **Mobile First**：先寫手機版（無前綴），再往上加 `md:`、`lg:`。
3. **重複就抽元件**，而不是狂複製 class。
4. **class 排序交給 Prettier**，不用手動整理。
5. **不確定 class 名稱**：靠 IntelliSense 或查官方文件，不要硬背全部。

## 附錄：常用工具類速查表

> **完整版**：[Tailwind CSS v4 完整速查表](cheatsheet.html) — 涵蓋所有分類、全部變體前綴、v4 CSS 語法與 v3 → v4 改名對照，並附關鍵字即時過濾。這裡只收課堂最常用的部分。

### 間距與尺寸

| Class | 說明 |
| --- | --- |
| `p-4` `px-4` `py-2` `pt-1` | padding（全 / 左右 / 上下 / 單邊）；**1 = 4px**，`p-4` = 16px |
| `m-4` `mx-auto` `mt-8` `-mt-2` | margin，`mx-auto` 水平置中，前面加 `-` 是負值 |
| `gap-4` `space-y-2` | Flex/Grid 間距 / 子元素之間的間距 |
| `w-full` `w-1/2` `w-64` `size-10` | 寬度 100% / 50% / 16rem；`size-*` 同時設寬高 |
| `h-screen` `min-h-screen` `max-w-md` | 視窗高 / 最小滿版高 / 最大寬度 |

### 文字與顏色

| Class | 說明 |
| --- | --- |
| `text-sm` `text-lg` `text-2xl` | 字級（xs / sm / base / lg / xl / 2xl…9xl） |
| `font-medium` `font-bold` | 字重 |
| `text-center` `text-right` | 對齊 |
| `leading-relaxed` `tracking-wide` | 行高 / 字距 |
| `truncate` `line-clamp-3` | 單行省略 / 限制三行 |
| `text-gray-600` `bg-blue-500` `border-gray-300` | 顏色公式 `屬性-色系-深淺`（50 最淺 → 950 最深） |
| `bg-black/50` `text-white/70` | 顏色透明度（v3 的 `bg-opacity-*` 已移除） |

### 佈局：Flex / Grid / 定位

| Class | 說明 |
| --- | --- |
| `flex` `flex-col` `flex-wrap` | 彈性容器 / 直向排列 / 允許換行 |
| `items-center` `justify-between` `justify-center` | 交叉軸對齊 / 主軸兩端 / 主軸置中 |
| `flex-1` `flex-[2]` `shrink-0` | 等分剩餘空間 / 兩倍比例 / 不縮小 |
| `grid` `grid-cols-3` `col-span-2` | 格線容器 / 三欄 / 跨兩欄 |
| `flex items-center justify-center` | 水平垂直置中（或 `grid place-items-center`） |
| `relative` `absolute` `fixed` `sticky` | 定位方式 |
| `inset-0` `top-4` `z-10` | 四邊定位 / 單邊偏移 / 層級 |
| `hidden` `block` `inline-block` | display（`hidden` 不佔位） |
| `overflow-hidden` `overflow-auto` | 溢出處理 |

### 外觀：邊框、圓角、陰影、效果

| Class | 說明 |
| --- | --- |
| `border` `border-2` `border-t` | 邊框粗細 / 單邊 |
| `rounded-sm` `rounded-lg` `rounded-2xl` `rounded-full` | 圓角（v4 的 `rounded-sm` = v3 的 `rounded`） |
| `shadow-sm` `shadow-md` `shadow-xl` | 陰影（v4 的 `shadow-sm` = v3 的 `shadow`） |
| `opacity-50` `blur-sm` `backdrop-blur-md` | 透明度 / 模糊 / 毛玻璃 |
| `transition` `duration-300` `ease-out` | 過渡效果 |
| `scale-105` `rotate-45` `translate-x-2` | 變形 |
| `bg-linear-to-r from-indigo-500 to-pink-500` | 漸層（v3 是 `bg-gradient-to-r`） |

### 變體前綴

| 前綴 | 說明 |
| --- | --- |
| （無）`sm:` `md:` `lg:` `xl:` `2xl:` | 手機 / 640 / 768 / 1024 / 1280 / 1536px 以上 |
| `max-md:` | 該斷點以下才生效 |
| `hover:` `focus:` `active:` `disabled:` | 互動狀態 |
| `group` + `group-hover:` | 依父層狀態改變子元素 |
| `peer` + `peer-focus:` `peer-invalid:` | 依前面兄弟元素的狀態改變 |
| `dark:` | 深色模式 |
| `before:` `after:` `placeholder:` | 偽元素 |
| `has-[:checked]:` | 內部包含某狀態時才套用 |

### 客製與逃生門

| 寫法 | 說明 |
| --- | --- |
| `w-[73%]` `bg-[#1da1f2]` `top-[117px]` | 任意值 |
| `p-13` `mt-27` | 刻度是動態的，沒列在文件裡的數字也能用 |
| `bg-red-500!` | `!important`（v4 改為後綴） |
| `@import "tailwindcss";` | 唯一需要的引入 |
| `@theme { --color-brand: #6366f1; }` | 自訂 token，產生 `bg-brand` 等工具類 |
| `@custom-variant dark (&:where(.dark, .dark *));` | 手動切換深色模式 |
| `@utility 名稱 { … }` | 自訂工具類（取代 v3 的 `@layer utilities`） |

## 重點速記

- Utility-First：在 HTML 組合小工具類，不寫 CSS。
- 間距刻度 **1 = 4px**，`p-4` = 16px。
- 顏色是 `屬性-色系-深淺`（50~950）。
- **Mobile First**：無前綴是手機，`md:`/`lg:` 是往上加。
- 狀態用 `hover:`/`focus:`，父子連動用 `group`/`peer`。
- 深色模式用 `dark:`。
- 用 `@import "tailwindcss"` + `@theme` 客製（v3 舊專案才用 `tailwind.config.js`）。
- 重複優先「元件化」，少用 `@apply`。

建議的練習順序：先看章節 → 打開[對應範例](#範例對照表)照著「動手改」提示改 class → 再到 `practice/` 自己刻一份。
