一顆 Button = 內容 + 間距 + 外觀 + 狀態

三種樣式的間距、圓角、字重完全一樣，只有顏色不同——這就是設計系統的一致性。

尺寸變化：只改內距與字級

↗ 圖示 + 文字

這一段的重點

  • 按鈕的四個層次：內容（文字／圖示）、間距（px-6 py-3.5）、外觀（rounded-xl 顏色 陰影）、狀態（hover / active / focus / disabled）。
  • 尺寸變化只動內距與字級，圓角與字重維持不變，一整組按鈕才會像同一個家族。
  • focus-visible: 只在鍵盤操作時顯示外框，滑鼠點擊不會跳出來，比 focus: 更貼近使用者預期。
  • transition 一定要寫，否則 hover 位移會是瞬間跳動而不是滑順動畫。
