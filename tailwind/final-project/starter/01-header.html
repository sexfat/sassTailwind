要做到的事

  1. 頁首固定在畫面上方，捲動時不會消失。
  2. 左邊：深色圓角方塊裡放字母 F，右邊接品牌名 Focusly。
  3. 中間：功能／使用方式／關於我們三個連結，手機隱藏、md 以上才顯示。
  4. 右邊：深色藥丸按鈕「免費開始」，以及一顆只在手機出現的漢堡按鈕。
  5. 點漢堡展開手機選單面板（連結垂直排列），再點一次收合。

會用到的 class

  • sticky top-0 z-50　固定頁首
  • mx-auto max-w-6xl px-6　內容置中並限制寬度
  • flex items-center justify-between h-20　左右兩端對齊
  • hidden md:flex gap-8　桌機才顯示的導覽
  • md:hidden　只在手機顯示的漢堡
  • classList.toggle('hidden')　JS 切換選單顯示
