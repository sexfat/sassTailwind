要做到的事

  1. 社會認同列：白底、上下細邊框，左邊一句文案、右邊四個品牌名。
  2. 這一列在手機是直向堆疊置中，md 以上變成左右兩端對齊。
  3. Footer：左邊版權、右邊兩個連結，同樣手機堆疊、sm 以上兩端對齊。
  4. 品牌名之間的間距用 gap-x-10 gap-y-3，換行時上下也要有間距。
  5. 連結加 hover 變深色的過場效果。

會用到的 class

  • flex flex-col md:flex-row　手機直向、桌機橫向
  • md:justify-between　兩端對齊
  • border-y border-ink/5　上下細邊框
  • flex-wrap gap-x-10 gap-y-3　會換行的排列
  • transition hover:text-ink　連結 hover
