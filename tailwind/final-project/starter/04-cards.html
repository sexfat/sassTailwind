要做到的事

  1. 先寫段落標題區：小標（品牌綠、字距加寬）、H2、說明段落。
  2. 先完成一張卡片：圖示色塊 → 標題 → 說明文字。
  3. 確認一張卡好看之後，再用 Grid 複製成三張。
  4. Grid 設定：手機一欄、md 以上三欄、間距 gap-6。
  5. 三張卡的圖示底色分別用 amber-100 / lime-100 / sky-100。
  6. 加上 hover：卡片微微上浮並加深陰影。

會用到的 class

  • grid gap-6 md:grid-cols-3　一欄 → 三欄
  • rounded-3xl border border-ink/5 bg-white p-7　卡片外觀
  • grid size-12 place-items-center rounded-2xl　圖示方塊置中
  • tracking-[0.2em]　小標字距
  • hover:-translate-y-1 hover:shadow-xl　卡片浮起
