要做到的事

  1. 做三種按鈕：主要（深底白字）、次要（白底外框）、強調（品牌綠底深字）。
  2. 三者的間距、圓角、字重一致，只有顏色不同。
  3. 加上互動狀態：hover 微微上浮、active 回到原位、focus-visible 有外框光暈。
  4. 再做一顆 disabled 狀態的按鈕（變淡、游標禁止）。
  5. 最後做一顆「圖示 + 文字」的按鈕，確認圖示與文字有正確對齊。

會用到的 class

  • px-6 py-3.5　內距＝按鈕大小
  • rounded-xl font-semibold　外觀
  • transition hover:-translate-y-0.5　hover 上浮
  • active:translate-y-0　按下回位
  • focus-visible:ring-2 ring-offset-2　鍵盤聚焦
  • disabled:opacity-50 disabled:cursor-not-allowed　停用狀態
