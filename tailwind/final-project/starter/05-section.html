要做到的事

  1. 整段換成深色底、白色文字，上下留大量空白（py-20 以上）。
  2. 版面用 Grid：手機一欄、lg 以上兩欄，左邊標題、右邊步驟清單。
  3. 步驟清單用 ol，每一項是「編號圓圈 + 標題 + 說明」的水平排列。
  4. 前兩個編號圓圈是綠色外框，第三個是綠色實心 + 深色數字。
  5. 深色底上的說明文字用較淺的灰（slate-400），不要用純白，才有層次。

會用到的 class

  • bg-ink text-white　深色段落
  • px-6 py-20 lg:py-24　大留白
  • grid gap-14 lg:grid-cols-2　雙欄敘事
  • space-y-8　清單項目間距
  • flex gap-5 / shrink-0　編號不被壓縮
  • rounded-full border border-brand/40　外框圓圈
