要做到的事

  1. 做一個品牌綠的大圓角區塊（圓角約 32px），內容全部置中。
  2. 內容：小標「今天就開始」→ H2 → 說明段落 → 深色按鈕。
  3. 左上與右下各放一個裝飾圓環（只有粗邊框、半透明白）。
  4. 裝飾圓環要被裁切在區塊內：外層加 overflow-hidden。
  5. 文字要蓋在裝飾之上：文字元素加 relative。

會用到的 class

  • rounded-[2rem] bg-brand　大圓角品牌色區塊
  • px-6 py-16 text-center　內距與置中
  • relative / overflow-hidden　裝飾定位與裁切
  • border-[12px] border-white/30　裝飾圓環
  • mx-auto max-w-xl　限制段落寬度
