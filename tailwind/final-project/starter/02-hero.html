要做到的事

  1. 整段用 Grid：手機一欄、lg 以上兩欄，欄距 gap-14。
  2. 左欄：小藥丸標籤（含一個小綠點）→ 大標題 → 說明段落 → 兩顆按鈕 → 一行小字。
  3. 大標題兩行，第二行要有螢光筆效果（綠色色塊墊在文字下半部）。
  4. 右欄：白色外框卡片，裡面是深色的產品畫面（先放色塊佔位也可以）。
  5. 幫整段加上背景光暈裝飾（模糊的圓形），記得容器要 overflow-hidden。

會用到的 class

  • grid gap-14 lg:grid-cols-2　單欄 → 雙欄
  • text-5xl sm:text-6xl lg:text-7xl　標題隨斷點放大
  • leading-[1.05] tracking-tight　大標的行高與字距
  • relative / absolute　螢光筆色塊定位
  • blur-3xl bg-brand/40　背景光暈
  • max-w-lg　限制段落寬度好閱讀
