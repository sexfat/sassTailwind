# Focusly Landing Page 切版練習（期末專題）

> 把一個完整的 Landing Page 拆成七個可以獨立練習的區塊。
> 題目頁：[exercises.html](exercises.html)　·　整頁完成版：[index.html](index.html)
> 設計稿：[Figma 完成稿](https://www.figma.com/design/usVgPWPxGlekwhcHjPVVU6/Focusly-Landing-Page?node-id=2-2)　·　[Figma 練習板](https://www.figma.com/design/usVgPWPxGlekwhcHjPVVU6/Focusly-Landing-Page?node-id=17-2)

## 怎麼進行

1. 先開整頁完成版看一次成品，縮放視窗觀察 RWD 行為。
2. 從第 01 題開始，打開 `starter/` 裡的起始檔，把 `TODO` 換成真正的 class。
3. 卡住時看起始檔右欄的「會用到的 class」提示，再不行才開 `answers/` 比對。
4. 七題都完成後，把七段組合成自己的一頁，對照 Figma 完成稿檢查細節。

每一題的起始檔都已經放好設計稿的色票與字體：

```css
@theme {
  --color-brand: #bbf451;        /* bg-brand / text-brand */
  --color-brand-strong: #9ae600;
  --color-brand-soft: #ecfcca;
  --color-brand-ink: #3c6300;
  --color-ink: #0f172b;          /* bg-ink / text-ink */
  --font-display: "DM Sans", "Noto Sans TC", system-ui, sans-serif;
}
```

## 01 · Header 與手機選單　`基礎`

> 起始檔：[starter/01-header.html](starter/01-header.html)　·　答案：[answers/01-header.html](answers/01-header.html)
> 對應講義：[5. Flexbox](../講義.md#5-flexbox-與-grid-佈局)、[6. RWD](../講義.md#6-響應式設計-rwd斷點)　·　[Figma](https://www.figma.com/design/usVgPWPxGlekwhcHjPVVU6/Focusly-Landing-Page?node-id=17-14)

- 頁首固定在畫面上方（sticky），捲動時不會消失。
- 左邊 Logo：深色圓角方塊 + 品牌名。
- 中間三個導覽連結：**手機隱藏、md 以上才顯示**。
- 右邊：深色藥丸按鈕 +**只在手機出現**的漢堡按鈕。
- 點漢堡展開手機選單面板，再點一次收合。

會用到：`sticky top-0 z-50`、`mx-auto max-w-6xl px-6`、`flex items-center justify-between h-20`、`hidden md:flex gap-8`、`md:hidden`、`classList.toggle('hidden')`

## 02 · Hero 雙欄版面　`基礎`

> 起始檔：[starter/02-hero.html](starter/02-hero.html)　·　答案：[answers/02-hero.html](answers/02-hero.html)
> 對應講義：[5. Grid](../講義.md#grid)、[6. RWD](../講義.md#6-響應式設計-rwd斷點)　·　[Figma](https://www.figma.com/design/usVgPWPxGlekwhcHjPVVU6/Focusly-Landing-Page?node-id=17-38)

- 整段用 Grid：手機一欄、lg 以上兩欄。
- 左欄：藥丸標籤 → 大標題 → 說明 → 兩顆按鈕 → 小字。
- 大標題第二行要有**螢光筆效果**（綠色色塊墊在文字下半部）。
- 右欄：白色外框卡片 + 深色產品畫面。
- 背景加模糊光暈裝飾，容器記得 `overflow-hidden`。

會用到：`grid gap-14 lg:grid-cols-2`、`text-5xl sm:text-6xl lg:text-7xl`、`leading-[1.05] tracking-tight`、`relative` / `absolute`、`blur-3xl`

## 03 · 按鈕的四個層次　`基礎`

> 起始檔：[starter/03-button.html](starter/03-button.html)　·　答案：[answers/03-button.html](answers/03-button.html)
> 對應講義：[7. 狀態變體](../講義.md#7-狀態變體hover--focus--group--peer)　·　[Figma](https://www.figma.com/design/usVgPWPxGlekwhcHjPVVU6/Focusly-Landing-Page?node-id=17-55)

一顆 Button = **內容 + 間距 + 外觀 + 狀態**。

- 主要（深底白字）、次要（白底外框）、強調（品牌綠）三種，間距圓角字重一致，只有顏色不同。
- 狀態：hover 微微上浮、active 回位、focus-visible 外框光暈。
- 再做 `disabled` 與「圖示 + 文字」兩種變化。

會用到：`px-6 py-3.5`、`rounded-xl font-semibold`、`transition hover:-translate-y-0.5`、`active:translate-y-0`、`focus-visible:ring-2 ring-offset-2`、`disabled:opacity-50`

## 04 · 卡片與響應式 Grid　`進階`

> 起始檔：[starter/04-cards.html](starter/04-cards.html)　·　答案：[answers/04-cards.html](answers/04-cards.html)
> 對應講義：[5. Grid](../講義.md#grid)、[6. RWD](../講義.md#6-響應式設計-rwd斷點)　·　[Figma](https://www.figma.com/design/usVgPWPxGlekwhcHjPVVU6/Focusly-Landing-Page?node-id=17-81)

- 先寫段落標題區（小標 + H2 + 說明）。
- **先完成一張卡片**（圖示色塊 → 標題 → 說明），再用 Grid 複製成三張。
- Grid：手機一欄、md 以上三欄、`gap-6`。
- 三張卡的圖示底色分別是 amber-100 / lime-100 / sky-100。
- 加上整張卡的 hover 上浮 + 陰影。

會用到：`grid gap-6 md:grid-cols-3`、`rounded-3xl border border-ink/5 bg-white p-7`、`grid size-12 place-items-center rounded-2xl`、`hover:-translate-y-1 hover:shadow-xl`

## 05 · 深色段落與編號清單　`進階`

> 起始檔：[starter/05-section.html](starter/05-section.html)　·　答案：[answers/05-section.html](answers/05-section.html)
> 對應講義：[5. Grid](../講義.md#5-flexbox-與-grid-佈局)、[4. 顏色](../講義.md#4-核心工具類速查)　·　[Figma](https://www.figma.com/design/usVgPWPxGlekwhcHjPVVU6/Focusly-Landing-Page?node-id=17-103)

- 整段換成深色底白色字，上下大留白。
- 版面：手機一欄、lg 以上兩欄（左標題、右步驟清單）。
- 每個步驟是「編號圓圈 + 標題 + 說明」的水平排列。
- 前兩個編號是綠色外框，第三個是綠色實心 + 深色數字。
- 深色底的說明文字用 slate-400，不要純白。

會用到：`bg-ink text-white`、`px-6 py-20 lg:py-24`、`grid gap-14 lg:grid-cols-2`、`space-y-8`、`flex gap-5`、`shrink-0`、`rounded-full border border-brand/40`

## 06 · CTA 收尾區塊　`挑戰`

> 起始檔：[starter/06-cta.html](starter/06-cta.html)　·　答案：[answers/06-cta.html](answers/06-cta.html)
> 對應講義：[9. @theme](../講義.md#9-自訂主題theme)　·　[Figma](https://www.figma.com/design/usVgPWPxGlekwhcHjPVVU6/Focusly-Landing-Page?node-id=17-130)

- 品牌綠的大圓角區塊，內容全部置中。
- 小標 → H2 → 說明 → 深色按鈕。
- 左上與右下各一個裝飾圓環（只有粗邊框、半透明白），要被裁切在區塊內。
- 文字要疊在裝飾之上；裝飾記得 `pointer-events-none`。

會用到：`rounded-[2rem] bg-brand`、`px-6 py-16 text-center`、`relative` / `overflow-hidden`、`border-[12px] border-white/30`、`mx-auto max-w-xl`

## 07 · 社會認同列與 Footer　`基礎`

> 起始檔：[starter/07-footer.html](starter/07-footer.html)　·　答案：[answers/07-footer.html](answers/07-footer.html)
> 對應講義：[5. Flexbox](../講義.md#flexbox)、[6. RWD](../講義.md#6-響應式設計-rwd斷點)

- 社會認同列：白底、上下細邊框，左文案右品牌名。
- **手機直向堆疊置中、md 以上左右兩端對齊**。
- Footer：左版權、右兩個連結，手機堆疊、sm 以上兩端對齊。
- 品牌名之間用 `gap-x-10 gap-y-3`，換行時上下也有間距。

會用到：`flex flex-col md:flex-row`、`md:justify-between`、`border-y border-ink/5`、`flex-wrap gap-x-10 gap-y-3`

## 全部做完後的延伸挑戰

1. 把七個區塊組成完整的一頁，順序照 Figma 完成稿。
2. 改 `@theme` 裡的 `--color-brand`，一行換掉整站主色。
3. 幫整頁加上深色模式（`dark:`），並在 Header 加一顆切換按鈕。
4. 把重複的按鈕樣式用 `@utility btn-primary { @apply … }` 抽成一個自訂類（v4 寫法，不是 v3 的 `@layer components`），比較前後的可讀性。
5. 手機選單改用純 CSS 做（`peer` + `peer-checked:block`），不寫 JS。
