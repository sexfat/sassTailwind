FINAL PROJECT

Focusly Landing Page 切版練習

把一個完整的 Landing Page 拆成七個可以獨立練習的區塊。每一題都有起始檔、參考答案，以及對應的 Figma 畫面與講義章節。

先看整頁完成版 → Figma 完成稿 Figma 練習板 回 Tailwind 講義 v4 速查表

怎麼進行

  1. 先開 整頁完成版 看一次成品，縮放視窗觀察 RWD 行為。
  2. 從第 01 題開始，打開 起始檔，照著「要做到的事」把 TODO 換成真正的 class。
  3. 卡住時看右欄「會用到的 class」提示，再不行才開 參考答案 比對。
  4. 七題都完成後，把七段組合成自己的一頁，對照 Figma 完成稿檢查細節。

每一題的起始檔都已經幫你放好設計稿的色票（bg-brand、text-ink）與字體，直接用就好，不用自己調色。

  • 01

    Header 與手機選單

    基礎

    品牌、導覽與主要行動的容器。重點是 flex justify-between 與「桌機顯示 / 手機收成漢堡」的切換。

    開始練習 參考答案 Figma 練習板 講義 5 講義 6
  • 02

    Hero 雙欄版面

    基礎

    先排大結構，再處理裡面的文字與卡片。練 lg:grid-cols-2、標題隨斷點放大，以及螢光筆標題效果。

    開始練習 參考答案 Figma 練習板 講義 5 講義 6
  • 03

    按鈕的四個層次

    基礎

    一顆 Button = 內容 + 間距 + 外觀 + 狀態。做出主要／次要／強調／停用四種，並加上 hover、active、focus-visible。

    開始練習 參考答案 Figma 練習板 講義 7
  • 04

    卡片與響應式 Grid

    進階

    先完成一張卡，再用 md:grid-cols-3 複製排列。順便練整張卡的 hover 效果。

    開始練習 參考答案 Figma 練習板 講義 5
  • 05

    深色段落與編號清單

    進階

    用背景色切換情緒，用雙欄建立敘事。編號圓圈要練 shrink-0 與深色底的文字層次。

    開始練習 參考答案 Figma 練習板 講義 5
  • 06

    CTA 收尾區塊

    挑戰

    用品牌色收束整頁，並加上被裁切的裝飾圓環。練 overflow-hidden 與絕對定位的疊層順序。

    開始練習 參考答案 Figma 練習板 講義 9
  • 07

    社會認同列與 Footer

    基礎

    兩個看似簡單的橫向區塊，重點是 flex-col md:flex-row 這個最常用的 RWD 反轉。

    開始練習 參考答案 Figma 完成稿 講義 5

全部做完後的延伸挑戰

  1. 01　把七個區塊組成完整的一頁，順序照 Figma 完成稿。
  2. 02　改 @theme 裡的 --color-brand，一行換掉整站主色。
  3. 03　幫整頁加上深色模式（dark:），並在 Header 加一顆切換按鈕。
  4. 04　把重複的按鈕樣式用 @utility btn-primary { @apply … } 抽成一個自訂類（v4 寫法，不是 v3 的 @layer components），比較前後的可讀性。
  5. 05　手機選單改用純 CSS 做（peer + peer-checked:block），不寫 JS。
