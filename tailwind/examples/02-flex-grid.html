動手練習（改完存檔重整看結果）

  1. 把「Flex 兩欄 A」改成左右 3:1（提示：flex-[3] + flex-1）。
  2. 把「Flex 兩欄 B / B3」修成真正的各半：w-1/2 改成 w-[calc(50%-0.5rem)]，或直接改用 flex-1。改完用開發者工具量一下寬度，確認 B 原本其實是 calc(50% - 8px) 而不是 50%。
  3. 用 flex-wrap + w-1/2 md:w-1/3 lg:w-1/4 做一個會自己換行的卡片牆。
  4. 做一個後台版面：左側欄 w-64 固定、右主內容 flex-1，整體 min-h-screen。
  5. 把「三欄 E」的 1/4 · 1/2 · 1/4 改成 RWD：手機用 flex-col 疊成一欄、桌機才三欄；再讓右側欄在平板以下隱藏（hidden lg:block）。
  6. 同一組三欄，分別用 Flex（flex-1）和 Grid（grid-cols-3）各做一次，比較把某一欄內容變很長時的差異。

選用原則：一維排列（一列或一行）用 Flex，欄列都要對齊的二維版面用 Grid；等分欄位優先 flex-1 或 grid-cols-*，需要精確比例才用 w-1/2 這類分數寬。
