通用規則

規則說明
命名公式屬性-值（bg-blue-500）；方向性屬性用 屬性方向-值（pt-4、mx-auto、border-t）。
間距刻度1 = 0.25rem = 4px，所以 p-4 = 16px、gap-2 = 8px。
動態刻度 v4刻度不再是固定清單，p-13、mt-27、w-113 這種沒列在文件裡的數字也能直接用。
顏色透明度任何顏色都能加 /數字：bg-black/50、text-white/70、border-blue-500/25。v3 的 bg-opacity-* 已移除。
負值class 前面加 -：-mt-4、-translate-x-2、-z-10。
任意值[值]：w-[73%]、top-[117px]、bg-[#1da1f2]、grid-cols-[1fr_2fr]（空白用 _）。
任意屬性[屬性:值]：[mask-type:luminance]、[--my-var:2rem]。
讀取 theme 值bg-(--my-color)、w-(--sidebar)，或在 CSS 用 var(--color-blue-500)。
!important v4後綴驚嘆號：bg-red-500!（v3 是前綴 !bg-red-500）。
前綴 prefix v4設定後寫成變體形式：tw:flex tw:bg-red-500。

v4 CSS 語法

語法用途
@import "tailwindcss";唯一必要的引入（取代 v3 的三行 @tailwind）
@theme { --color-brand: #6366f1; }定義設計 token，自動產生 bg-brand / text-brand 等工具類
@theme { --breakpoint-3xl: 120rem; }新增斷點，產生 3xl: 前綴
@theme inline { … }token 值直接內聯展開，適合引用其他變數時
@custom-variant dark (&:where(.dark, .dark *));自訂變體（此例＝手動切換深色模式）
@utility tab-4 { tab-size: 4; }自訂工具類（取代 v3 的 @layer utilities）
@apply px-4 py-2 rounded-lg;把工具類組合成語意化 class（建議少用，優先元件化）
@source "../node_modules/ui-lib";手動加入要掃描的來源（v4 預設自動偵測）
@reference "../app.css";在 Vue/Svelte 的 <style> 內使用 @apply 前先引用主樣式
@config "../tailwind.config.js";相容模式：沿用 v3 設定檔
var(--color-blue-500)在自訂 CSS 直接取用 theme 值（v3 的 theme() 函式仍可用但不建議）
@import "tailwindcss";

@theme {
  --color-brand: oklch(0.62 0.19 264);   /* bg-brand / text-brand / border-brand */
  --font-display: "Noto Sans TC", sans-serif;
  --spacing-18: 4.5rem;                  /* p-18 / m-18 / gap-18 */
  --breakpoint-3xl: 120rem;              /* 3xl: 前綴 */
}

@custom-variant dark (&:where(.dark, .dark *));

@utility content-auto {
  content-visibility: auto;
}

v4 的預設色票改用 oklch 色彩空間，在廣色域螢幕上更鮮豔；語法本身沒變，bg-blue-500 照用。
